Анализ модели CNN.
В данном задании проводится анализ качества аппроксимации выборки EMNIST-letters моделью
сверточной нейронной сети в зависимости от:
размера ядра;
числа слоев;
от пулинга;
добавления BatchNorm;
параметра dropout.
Все выводы представлены в формате tensorboard.
В данном задании демонстрируется умение строить
различные структуры модели CNN.
